# AI 费用报销自动审计原型

## 一、项目目标
验证“规则引擎 + 大模型”双路径审计的可行性，落地三个核心点：

- **边界**：区分可写成代码的确定性规则与必须交大模型判断的语义规则；
- **裁决**：双路径一致才输出，冲突或证据不足降级人工，确定性规则优先；
- **证据**：每条结论附字段级证据与 SHA-256 哈希，支持第三方复算。

## 三、运行方式

环境：Python 3.10+。

### 1. 安装依赖

pip install openai python-dotenv

### 2. 配置 `.env`

LLM_BACKEND=openai
LLM_API_KEY=sk - 你的密钥
LLM_BASE_URL=[https://api.deepseek.com](https://api.deepseek.com)
LLM_MODEL=deepseek-flash

切回离线 mock：将 `LLM_BACKEND` 改为 `mock`，无需密钥。

### 3. 运行主程序


控制台输出分级汇总，明细写入 `output/audit_result.json`，并自动完成哈希复算自检。

## 四、规则清单

| 规则 ID | 名称 | 类型 | 说明 |
|---|---|---|---|
| D1 | 重复发票 | 确定性 | 同一发票号出现多次 |
| D2 | 疑似拆单 | 确定性 | 同人同供应商近窗口多张合计超限 |
| D3 | 金额超限 | 确定性 | 按类别政策上限比对 |
| D4 | 超部门预算 | 确定性 | 单据金额 vs 部门预算 |
| D5 | 科目关键词不符 | 语义辅助 | 关键词未命中，最终由大模型判断实质 |
| D6 | 事由证据不足 | 确定性 | 事由过短，信息不足 |

## 五、裁决逻辑

- 模型证据不足/调用失败 → **high，降级人工**；
- 命中确定性规则 → **high，人工复核**（规则结论优先，不被模型一致判断翻案）；
- 语义规则与模型均提示不符 → **high，人工复核**；
- 语义规则命中但模型判一致 → **medium，人工抽复核**；
- 规则未命中、模型提示不符 → **medium，人工复核**；
- 双路径一致且置信度 ≥ 0.7 → **自动通过**。

## 六、输出说明

`audit_result.json` 每条记录包含：

- `verdict`：分级（high/medium/pass）与动作；
- `rule_findings`：规则命中项与字段级证据；
- `llm_decision`：模型判断、置信度、理由；
- `evidence`：证据包与 `evidence_hash`。
